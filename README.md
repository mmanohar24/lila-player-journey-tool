# LILA BLACK — Player Journey Visualization Tool

A Next.js tool for LILA's Level Design team to explore player movement, combat,
and death patterns from LILA BLACK gameplay telemetry.

See `PRD.md` for the product spec, `design.md`/`brandguidelines.md` for the
visual system, and `ARCHITECTURE.md` (added once the build is further along)
for implementation details and tradeoffs. The raw dataset and its own schema
README live in `player_data/`.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
